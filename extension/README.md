# Vently

An open-source job application automation platform.

## Overview

Vently aims to simplify job and internship applications through browser autofill, intelligent resume parsing, AI-powered assistance, and application tracking.

## Project Structure

- `frontend/` - Web application
- `backend/` - Backend APIs and services
- `extension/` - Browser extension
- `docs/` - Project documentation

## Status

Currently under development.
